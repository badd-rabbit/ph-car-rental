#  PH Car Rental System

A modern, full-stack car rental management platform built for the Philippine market.

![Tech Stack](https://img.shields.io/badge/Stack-FastAPI%20%7C%20React%20%7C%20PostgreSQL-blue)
![License](https://img.shields.io/badge/License-MIT-green)

##  Features

### User Features
-  **Secure Authentication** - JWT-based auth with role-based access control
- 🚙 **Car Browsing** - Filter by vehicle type, fuel type, and availability
- 📅 **Smart Booking** - Professional date/time picker with real-time cost calculation
- 💳 **Multiple Payment Options** - Cash, GCash, Maya, Bank Transfer
-  **Feedback System** - Rate and review rentals (editable within 24 hours)
-  **Real-time Notifications** - Stay updated on booking status
- 💬 **AI Chatbot** - Instant answers to common questions

### Admin Features
-  **Staff Management** - Create and manage staff accounts
- 📊 **Booking Management** - Approve/disapprove/complete bookings
- 🚗 **Fleet Management** - Add/edit/delete cars with multiple images
- 📈 **Dashboard Analytics** - Track bookings and revenue

### Technical Highlights
- ️ **3-Minute Cancellation Window** - Auto-expiring cancellation feature
-  **One-Time Setup** - Secure initial admin configuration
- 📱 **Responsive Design** - Mobile-friendly UI with Tailwind CSS
- 🎨 **Modern UI/UX** - Professional gradients, animations, and glassmorphism

## 🛠️ Tech Stack

### Backend
- **FastAPI** - Modern Python web framework
- **PostgreSQL** - Relational database
- **SQLAlchemy** - ORM for database operations
- **JWT** - Secure token-based authentication
- **Passlib** - Password hashing
- **Pydantic** - Data validation

### Frontend
- **React** - UI library
- **React Router** - Navigation
- **Tailwind CSS** - Styling
- **React DatePicker** - Professional date/time selection
- **React Toastify** - Notifications
- **Axios** - HTTP client

### DevOps
- **Docker** - Containerization
- **Docker Compose** - Multi-container orchestration

## 📋 Prerequisites

- Python 3.11+
- Node.js 18+
- Docker & Docker Compose
- PostgreSQL (or use Docker)
